System Architecture

End-to-end data pipeline from document ingestion to LLM-powered semantic analysis.

Text
Extraction

Parses structural data from PDF & DOCX formats into raw, readable text.

Smart
Chunking

Splits document into ~120-word overlapping text chunks.

Vector
Embeddings

Converts chunks to 384-dimensional vectors via MiniLM model.

FAISS
Indexing

Stores embeddings in a high-speed, GPU-accelerated vector database.

Semantic
Retrieval

Matches embedded Job Description against top-5 relevant resume sections.

Gemini
Analysis

Evaluates retrieved context to generate match score and structured feedback.
