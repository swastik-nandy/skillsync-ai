Two Deployment Options

Flexible architectures tailored for cloud scalability or strict data privacy.

Option 1: Cloud-Based

  • Primary Stack: Gemini API + FAISS
  • Core Scripts: analyzer.py & pipeline.py
  • Leverages external APIs for heavy LLM lifting.
  • Ideal for environments prioritizing speed and requiring low local compute overhead.

Option 2: 100% Local

  • Primary Stack: LangChain + Local LLM
  • Core Scripts: rag_pipeline.py
  • Zero external API calls ensure complete data privacy for sensitive resumes.
  • Requires adequate local hardware (GPU recommended).

Fallback Capability: Integrates TinyLlama-1.1B as an emergency offline model for strict CPU-only environments.
