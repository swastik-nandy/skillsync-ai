Core Components

Modular, robust architecture designed for high-performance semantic processing.

Extractor

Robust document parsing engine supporting PDF, DOCX, and plain text formats while preserving crucial structural data.

Embedder

Utilizes SentenceTransformer (all-MiniLM-L6-v2) to generate dense 384-dimensional vector representations of text.

Analyzer

High-performance FAISS indexing engine enabling rapid and accurate semantic search across structured resume chunks.

LLM Generation

Deep Google Gemini API integration featuring ultra-fast 2.5-Flash processing with automatic fallback to 2.5-Pro on errors.

GPU Support

Intelligent hardware acceleration that auto-detects and utilizes CUDA for embedding operations, with seamless CPU fallback.
